# Demonstration guide

1. Sign in as Administrator using admin@aap.demo / Demo@123. Show calculated dashboards, filters, audit lists and activity logs.
2. Open Users & roles, Departments, Programs and Courses. Add/edit synthetic records. A dependent program cannot be deleted; deactivate it instead.
3. Create an audit with Department → CSE, Dr. Arjun Sethi as coordinator, Dr. Kabir Mehta as auditor and Course file completeness as criterion. It begins in Draft. Move to Evidence Collection and confirm.
4. Sign out and sign in as faculty@aap.demo. Open the new audit → Criteria → Submit evidence. Select a small local PDF or TXT file, enter a title and description, and submit. Show Pending Review, file metadata and download availability. Faculty cannot edit criteria or close audits.
5. Sign in as auditor@aap.demo. Open Evidence library → the submission → Review evidence. Request revisions with a reason. As Faculty, resubmit a new file; show both versions. As Auditor, accept the latest version.
6. Open the audit's Criteria tab. Record an evaluation and auditor comments. Create an observation after reviewing evidence. Assign a corrective action to Dr. Riya Kapoor with a due date.
7. As Faculty, open the assigned action and submit an action-taken description with a supporting file. As Auditor, request modifications or approve the submission. Verify and close the observation only after every linked action is approved.
8. Move the audit through Evaluation / Review, Corrective Action and Closure Review. Read blockers. Set the criterion to Compliant if the issue has been resolved. Confirm final closure. Show the closure date, actor and saved report.
9. For a quick closure demonstration, seeded AAP-2026-005 is ready. AAP-2026-001 is deliberately blocked. OBS-004 is already closed and can be reopened by the assigned auditor; reopening preserves history and requires action revision.
10. Use audit comments and Notify users. Faculty can message administrators; administrators can notify authorized participants. Switch accounts to see inbox/read status and resubmission notifications.
11. Sign in as hod@aap.demo for department responsibilities and management@aap.demo for consolidated read-only dashboards. Explore report filters; export PDF and CSV.
12. Refresh to demonstrate record persistence and the explicit file-byte limitation. Use Profile & demo settings → Restore demo data to return to the original scenario.

Use one browser tab for editing. Switching roles through logout preserves the same local dataset. `localhost` and `127.0.0.1` are separate demo datasets. All accounts and files used for evaluation should remain synthetic.
